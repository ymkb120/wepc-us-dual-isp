## 9929 解决的是回国路由，双 ISP 解决的是 IP 身份

这两件事经常被混成一件事，其实是两个维度。

AS9929 是联通的 CUII 精品网，定位上对标电信的 CN2 GIA。普通美国机器回国走 163 骨干，晚高峰容易绕路和丢包；9929 是优先级更高的通道，回程强制走这条线再分送给三网。它改善的是「国内访问这台机器稳不稳」，和你从这台机器访问 TikTok 没有关系。WePC 页面把 9929 三档标成「直播无需中转」，指的就是这一层。

双 ISP 说的是 IP 在 ASN 和 Company 字段被识别成 ISP 类型、归属宽带运营商，而不是机房。平台风控看到这类 IP，判断逻辑接近「一个美国家庭用户在上网」。TikTok 起号、发视频、跑矩阵，看的正是这一层。两项配置互不替代：一台机器可以只有 9929 没有双 ISP，也可以只有双 ISP 走 4837，WePC 的 5 档就是这么拆的。

要提醒一句，双 ISP 提高的是被判定为住宅用户的概率，不是保证。平台风控是动态的，某个 IP 段被大量滥用之后可能临时降级，商家页面上的「原生」「双 ISP」都不承诺长期解锁。买之前用页面提供的测试方式自己验一遍，比看宣传语有用。
